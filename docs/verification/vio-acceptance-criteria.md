# VIO受入れ基準

## 方針

数値は実装都合で決めず、利用条件、データセット、計測方法と一緒にレビューして確定する。TBDの項目が残る間、実装・測定は行えても量産・自走用VIOとして合格判定しない。

## ゲート

| ゲート | 確認内容 | 合格条件 |
| --- | --- | --- |
| VIO-G0 | 仕様 | topic、frame、時刻、状態、異常処理、試験方法がレビュー済み |
| VIO-G1 | カメラ | 固定条件内部較正、RMS、Image/CameraInfo整合、欠落診断が合格 |
| VIO-G2 | IMU | 公式初期化、200 Hz、FIFO/IRQ/SENSORTIME、較正、欠損診断が合格 |
| VIO-G3 | Camera-IMU | 外部・時刻較正と個体・取付トレーサビリティが合格 |
| VIO-G4 | 再生 | 公開データセットとmower rosbag2で再現性・精度が合格 |
| VIO-G5 | Pi 5 | 実時間性、資源、温度、連続動作が合格 |
| VIO-G6 | 手押し | 実環境の追跡、ドリフト、故障検出が合格 |
| VIO-G7 | 上位統合 | DEGRADED/LOSTが上位へ伝達され、安全系分離が維持される |

## 必須試験条件

- 静止、直線、旋回、閉ループ
- 芝、低テクスチャ、草の揺れ、影、逆光
- 振動、防水窓の汚れ、水滴を模擬した条件
- カメラ停止、低FPS、IMU欠損、時刻逆行、CPU過負荷、Pi再起動

物理的な停止距離および最終安全性能はVIO受入れ試験の対象外であり、外部MCU・独立安全回路を含む安全検証で確認する。
