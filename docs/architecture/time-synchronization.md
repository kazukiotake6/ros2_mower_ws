# センサー時刻同期仕様

## 時刻源

- カメラはlibcameraのフレーム開始に対応するハードウェア時刻をPiの単調時刻へ対応付け、ROS時刻へ変換する。
- BMI270はSENSORTIMEをIRQ受信時のPi単調時刻へ対応付け、ROS時刻へ変換する。
- Publish callbackの実行時刻を取得時刻の代用にしない。

## 必須処理

- SENSORTIMEとカメラ時刻のロールオーバーを処理する。
- ROS時刻変換後も各センサーストリームの単調性を検査する。
- 時刻逆行、重複、過大gap、許容値を超えるジッタを拒否またはDEGRADEDとして通知する。
- システム時刻補正がセンサー間相対時刻を不連続にしない構成とする。

## 実測

ロジックアナライザで、カメラのフレーム開始、BMI270 INT1、画像Publishを同時測定する。試験記録には平均オフセット、最大ジッタ、測定時間、温度・負荷条件、連続運転中のドリフトを残す。
